# Memory on the GitHub Copilot harness (B10)

- Scope: per user, stored as files in Microsoft-managed storage; deleted after 28 days of inactivity.
- The user sees and can delete their memories in a portal; the maker cannot read them.
- Switch on under the agent's Memory setting; nothing to provision.
- What it is for here: "my card is a Platinum" or "I prefer email" carries into the next session.
- What it is not: ticket state. Ticket facts stay in the ticket system and arrive through tools every time.
- Customer Conversation harness has a separate structured memory (G2); persistent agents get business-process memory in Frontier (G3).

Same thing elsewhere: Foundry memory store + memory search tool (F03 lab 04); AgentCore Memory with semantic and user-preference strategies (B03 lab 04).
