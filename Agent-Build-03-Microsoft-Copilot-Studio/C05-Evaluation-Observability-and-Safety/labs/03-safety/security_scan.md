# The pre-publish security scan and the protection status

Reading map E6, F13. On publish the scan warns on: **No authentication**, **maker credentials** on a tool, **tenant-wide sharing**. The agent list shows a **Protection status** column (Protected / Needs review / Unknown) across authentication, policies and content moderation, with security analytics that list block reasons.

For the ticket agent the three answers should be: Authenticate with Microsoft, end-user credentials on the MCP tool, shared with a security group. Any other answer is a C09 conversation.
