# Monitor (the page formerly called Analytics)

Reading map H1. Copilot Studio → the agent → **Monitor**.

- **AI summary** and **Overview**: DAU/MAU (needs an authenticated agent), sessions, outcomes.
- **Conversational sessions**: Resolved / Escalated / Abandoned, CSAT; click through to the session detail (28 days) and the activity map.
- **Event-trigger sessions**: runs started by triggers (C03 lab 03), with knowledge-source use.
- **Topic monitor** (Standard harness only): per-topic rates; under generative orchestration read Outcomes and Themes instead.
- **Evaluations**: the test sets and runs from lab 01.
- **Custom metrics** (preview, Apr 2026) and CSV export of questions and reactions (Mar 2026).
- Retention: 360 days aggregate, 28 days of session detail. Role: Analytics Viewer lets someone read this without edit rights.

The test pane is excluded; to see a conversation here, use a published channel.
