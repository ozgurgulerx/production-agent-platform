# Reading notes

One page per reference document the platform is built from, written from memory after the read and then checked against the source. These are recall notes, not summaries: what the document says that changed a decision here, and what it gets quoted for in an interview.

File name: `<vendor>-<doc>.md`. Header fields: source URL, date read, recite score 0–4 (self-graded after writing the note without the source open), cards produced and the Anki deck they went to, and the stage or ADR the note fed.
