# Study log

Create YYYY-MM-DD.md only after a real session. Record module and requirement IDs; question or exercise; your answer or evidence link; assistance used; architecture/code score and justification; observed gap; next check. Use “unassessed” when evidence is insufficient. Include dataset, environment and measurement method for numerical results. Do not store access tokens, private customer data or raw job correspondence.

For an unaided F3 drill, record time limit, actual time, allowed references and outcome. A generated answer or completed chapter is not proof of mastery. No dated sessions have been fabricated by this update.
