# Gemini Enterprise Agent Platform — agent creation, runtime, tooling, evals and governance reading map (25 Oct 2026)

Crawl of the Google Cloud documentation (docs.cloud.google.com), adk.dev, mcp-toolbox.dev, a2a-protocol.org and the GitHub release pages that G01–G09 are written from. Dates are the "last updated" stamp on the page on 25 Oct 2026; "undated" where the page carries none. Where a page could not be fetched it is listed under "Gaps" at the end and the chapter that would quote it says so. The companion runnable code is the `labs/` folder of each chapter, lab numbers in brackets.

Status words used: **GA**, **preview**, **experimental**, **deprecated**, **retiring**. Where two sources disagree the newer one is noted.

## Naming, as of this crawl

On **22 Apr 2026** Google renamed Vertex AI to **Gemini Enterprise Agent Platform** and Vertex AI Agent Engine to **Agent Runtime** (A1, A2). Vertex AI Search is **Agent Search**, Vertex AI Studio is **Agent Studio**, the Gen AI evaluation service is **Agent Platform Evals**. API resource ids did not change: `aiplatform.googleapis.com`, `reasoningEngines`, `discoveryengine.googleapis.com`. **Gemini Enterprise** (the end-user product, ex-Agentspace, renamed Oct 2025) sits on top of the platform; its admin role is still `discoveryengine.agentspaceAdmin` (C9). Old URLs under cloud.google.com 301 to docs.cloud.google.com; google.github.io/adk-docs 301s to adk.dev. Chapters use the new names and give the old one once in brackets.

## Interview model to carry

Three layers. **Gemini Enterprise** is the end-user app; admins register agents either as ADK agents by `reasoningEngines` resource path or as A2A agents by pasted agent card (C8, C9). **Gemini Enterprise Agent Platform** is the builder's platform: Build (ADK 2.13, Agent Studio, Agent Garden preview), Scale (Agent Runtime, API resource still `ReasoningEngine`; Sessions and Memory Bank GA on `us`/`eu`/`global`; Code Execution and Computer Use sandboxes GA), Govern (Agent Registry GA 18 Jun 2026 with A2A 1.0, Agent Identity GA 22 Apr 2026 with SPIFFE principals in place of service accounts, Agent Gateway GA, Model Armor), Optimize (Evals, Observability GA with OpenTelemetry on by default). **Code** is ADK: `LlmAgent`, `SequentialAgent`/`LoopAgent`/`ParallelAgent`, `BaseAgent`, graph workflows new in 2.0; `Runner` plus a session service; `adk web|run|api_server|deploy agent_engine|deploy cloud_run`; `McpToolset`, `OpenAPIToolset`, `to_a2a`, `RemoteA2aAgent`. The deploy SDK is mid-migration: `vertexai.agent_engines` is old, `agentplatform.Client().runtimes` in `google-cloud-agentplatform` 2.x is new (A5, C2). Revisions and traffic split are preview; rollback means shifting traffic to an earlier active revision (C4).

## Foundry ↔ GCP concept map

| Foundry (Agent-Build-02)                    | GCP (this track)                                                                        | Where they differ                                                                                    |
| ------------------------------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Foundry resource + project                  | GCP project + region (+ `us`/`eu`/`global` endpoints)                                   | No project-in-account hierarchy; folder/org policy does the tiering (I1, I5)                         |
| Agent Service (prompt / hosted agents)      | Agent Runtime (`ReasoningEngine`)                                                       | No "prompt agent" object; every agent is code deployed from source, pickle, Dockerfile or image (I7) |
| `PromptAgentDefinition` + `POST /responses` | ADK `LlmAgent` + `:query` / `:streamQuery` on the resource                              | Invocation surface is per-agent REST, not one Responses endpoint (C3)                                |
| Hosted agent, Agent Framework               | ADK app on Agent Runtime, or Cloud Run via `adk deploy cloud_run`                       | Agent Runtime builds the container for you; Cloud Run is the self-host path (B7, C2)                 |
| Agent Framework workflows                   | ADK Sequential/Loop/Parallel/graph workflows                                            | Workflows are in-process code, not a separate hosted type (B2)                                       |
| Memory store + memory search tool           | Memory Bank + Sessions                                                                  | GA, metered as Agent Platform compute since Sep 2026 (A2)                                            |
| Entra Agent ID (blueprint → instance)       | Agent Identity (SPIFFE principal, `identity_type=AGENT_IDENTITY`)                       | Opt-in per deployment; unset means service account (C5, D9, D10)                                     |
| Six connection auth types                   | ADK `AuthScheme` + `AuthCredentialTypes` (API key, HTTP, OAuth2, OIDC, service account) | Auth is per tool/toolset in code, not a project-level connection object (D5)                         |
| Toolbox                                     | MCP Toolbox for Databases (`tools.yaml`) + Agent Registry                               | Toolbox is a DB-MCP server you host; the registry is the catalogue (D6, D7, F7)                      |
| APIM + API Center                           | Apigee MCP + API hub                                                                    | Apigee ingests OpenAPI and serves tools; API hub MCP server GA Jul 2026 (D12, D13)                   |
| A2A v1.0 tool                               | `RemoteA2aAgent` / `to_a2a`, Agent Registry                                             | Experimental in ADK; Gemini Enterprise still speaks 0.3 streaming (C7, C9)                           |
| Evaluators, batch and continuous evals      | ADK `adk eval` + Agent Platform Evals (`client.evals`, `EvalTask`)                      | Trajectory metrics are first class; agent evaluation module is preview (E1–E3)                       |
| App Insights tracing                        | Cloud Trace via OpenTelemetry, Cloud Logging, Cloud Monitoring                          | On by default for new ADK agents on Agent Runtime (E4–E6)                                            |
| Content safety + guardrails                 | Model Armor floor settings + Gemini safety settings                                     | Floor settings bind at org/folder/project; templates cannot be weaker (F1, F2)                       |
| Foundry IQ knowledge base                   | Agent Search data store / RAG Engine corpus / grounding tool                            | Three products, one decision (H9, H11–H13)                                                           |
| Fine-tuning (SFT)                           | Supervised tuning via `client.tunings.tune`, JSONL `contents`                           | `us`/`eu` multi-region endpoints for Gemini 3.x (G2, G4)                                             |
| Foundry Local                               | Gemma 4 via Ollama/llama.cpp, ADK `LiteLlm`                                             | Same ADK code, model string changes (H2, H8)                                                         |
| Landing zone (Basic/Standard)               | VPC-SC perimeter, PSC interface, CMEK, org policy `vertexai.allowedModels`              | Agent Runtime has no internet egress inside VPC-SC (I2, I3)                                          |
