# Agent-Build-05 — Gemini Enterprise Agent Platform (Google Cloud)

The Google Cloud counterpart of the Foundry track in `Agent-Build-02`. Same running scenario (the S03 support-ticket agent), same chapter order, same bar: every claim is backed by a lab that runs against a real project, and every fact cites the dated reading map in [`reference/reading-map-gcp-agents-2026-10-25.md`](reference/reading-map-gcp-agents-2026-10-25.md). The side-by-side with Foundry is [`reference/foundry-vs-gcp.md`](reference/foundry-vs-gcp.md). Setup is [`labs-setup/`](labs-setup/README.md).

Naming, since 22 Apr 2026 (map A1, A2): Vertex AI is **Gemini Enterprise Agent Platform**, Agent Engine is **Agent Runtime** (API resource still `ReasoningEngine`), Vertex AI Search is **Agent Search**. **Gemini Enterprise** is the end-user product on top (ex-Agentspace).
