# Card policy (ticket-agent lab fixture)

Document: card-policy. Version 2, effective 1 September 2026.

1. Cards may be used abroad; a foreign transaction fee of 2.5% applies.
2. A card reported lost is blocked immediately and a replacement ships within 3 working days.
3. Contactless limit is 100 per transaction; the customer can lower it in the app.
4. Disputed transactions must be raised within 120 days.
