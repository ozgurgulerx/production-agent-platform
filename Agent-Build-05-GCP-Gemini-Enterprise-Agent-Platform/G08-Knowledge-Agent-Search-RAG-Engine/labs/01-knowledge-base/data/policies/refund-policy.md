# Refund policy (ticket-agent lab fixture)

Document: refund-policy. Version 3, effective 1 October 2026.

1. Refunds are available within 30 days of purchase for unused items in original condition.
2. Between 31 and 60 days a store credit is offered instead of a refund.
3. After 60 days no refund or credit is given. Agents must not promise refunds outside this window; this is "refund outside policy".
4. Digital goods are refundable only if not downloaded.
5. Refunds go back to the original payment method within 5 working days.
