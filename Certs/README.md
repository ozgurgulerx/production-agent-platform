# Certs

Certification study kits. One folder per exam. Each folder has a hub `README.md` (official links, exam facts, how to use the folder), one file per blueprint domain (official objectives as checkboxes, a one-line "know how to" per objective, and the fundamental reading links), and a `progress.md` tracker.

Blueprints were copied from the official study guides on 25 Oct 2026. Re-check the "skills as of" date on each hub README before a sitting; Microsoft and AWS revise outlines several times a year.

## Conventions

- Objectives are quoted verbatim from the vendor outline, as `- [ ]` checkboxes. Tick them in the domain file, not the tracker.
- **Know how to** lines are the hands-on bar for each objective: short, because the reader already works with these platforms.
- **Read** lists the primary doc first, then one blog, sample or video. Status words (GA, preview, retiring) are those printed on the page on 25 Oct 2026.
- **In repo** points at existing chapters under `Agent-Build-01-Fundamentals` and `Agent-Build-02-Microsoft-Foundry` that already cover the topic. Nothing is duplicated here.
- Third-party guides are listed under "Community" and labelled as unofficial.
